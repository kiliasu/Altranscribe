# 云端服务

[English](../en/cloud-providers.md) | 简体中文 · [首页](../../README.zh-CN.md)

Windows 和 Android 均支持 OpenAI 与 Google Gemini，无需下载云端模型。使用前需准备提供商的 API Key、可用额度和模型访问权限。

## 配置

1. 打开「设置 → 模型选择」，选择 OpenAI 或 Gemini，输入并保存 API Key。
2. 选择实时原文转录或实时直译；文件转录使用面板显示的文件模型。
3. 如需文字翻译、标题或摘要，在「设置 → 翻译选择」选择提供商与文字模型。相同提供商复用已保存的 Key。
4. 保存配置，回到首页选择音源与语言并开始。

原文转录可接独立文字翻译。实时直译直接返回原文和译文，但标题与摘要仍需文字模型。关闭翻译后，实时音频使用原文转录模式。云端默认自动识别源语言；实时直译只指定目标语言。

模型列表查询成功不代表账户拥有所有模型的调用权限。遇到权限或额度错误时，请检查提供商账户及面板显示的模型名称。

## 使用与费用

- 麦克风和系统音频分别连接并计费。暂停后停止上传新音频。
- 实时直译可能产生译文语音，即使应用不播放，提供商仍可能计费。
- 长文件分段提交；原文件不会被修改。Gemini 文件转录会临时上传音频，任务结束后应用尝试删除，删除失败会提示。
- 「停止并保存」后尾句、译文与摘要继续收尾；收尾完成前暂不能开始下一场。
- 网络断线或额度不足时保留已收到的文字，不自动重试付费推理。

## 已知限制

Gemini 长会话会自动续接。切换连接可能造成断词，不能保证连续识别完全无损。直译预览接口可能不返回最终完成确认，此时文稿会标记未确认；停止后的等待也不能保证延迟尾句完整。

时间码与原文、译文的分组可能为估算。模型输出需核对，长时间双路运行的稳定性会受网络和服务端限制影响。

API Key 由 Windows DPAPI 或 Android Keystore 加密保存，不写入文稿。换用户或设备后需要重新输入。音频与文字发送至提供商的官方接口，费用与数据处理规则以所选提供商的说明为准。
