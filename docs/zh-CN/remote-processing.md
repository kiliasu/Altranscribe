# 连接 Windows 主机

[English](../en/remote-processing.md) | 简体中文 · [首页](../../README.zh-CN.md)

Windows 电脑可以共享本地 Whisper 和文字模型，供另一台 Windows 电脑或 Android 手机使用。客户端负责采集、字幕与文稿保存，主机负责识别、翻译和摘要。

## 配对设备

1. 在主机准备 Whisper 程序和模型。如需翻译或摘要，启动并配置本机 Ollama 或 OpenAI 兼容文字服务。
2. 在主机「设备」页开启共享：选择网卡地址、端口（默认 8178）、模型与 CPU / GPU，按需共享文字模型，然后启动。面板随即显示二维码和 6 位配对码；之后也可以在同一页点「添加设备」重新打开。
3. Android 手机打开「设备 → 扫码配对」，对准二维码即可。Windows 客户端或没有相机时，选择「连接主机」：同一网络里正在共享的主机会列在「附近的主机」中，选择一台或手动输入地址，再填入配对码。也可以把主机面板上复制的邀请链接粘贴到地址栏。
4. 主机随即成为处理引擎。回到首页开始实时或文件转录。已连接主机时，「设置 → 翻译选择」可以在主机共享的文字模型（默认）和自行配置的服务（例如 OpenAI 或在线 OpenAI 兼容服务）之间选择；若主机没有共享文字模型，就在那里改用自己的服务，或关闭翻译、标题摘要和文件优化。
5. 切回本地或云端时，在「设置 → 模型选择」保存其他引擎。

配对码 10 分钟内有效，用过一次即失效；关闭主机的共享面板会结束它，「换一个码」可以生成新的。每台配对的设备都有自己的凭据，重启共享后仍然有效，直到在主机「已配对设备」列表中移除。0.6.1 及更早的主机没有配对码，仍可输入它显示的令牌。

客户端无需安装 Whisper 或下载权重。Windows 文件转录仍需要本机 FFmpeg，Android 已包含解码组件。

## 状态与发现

- 「设备」页会显示已保存主机是在线、忙碌还是离线，页面打开期间每 20 秒检查一次；主机端则显示每台配对设备最近在线的时间。
- 主机通过 UDP 47653 端口应答同一网络内设备的查找请求。若已保存的主机之后换了地址（例如 DHCP 重新分配），客户端会自动更新地址。发现不跨网络；使用 Tailscale 时请按地址连接。
- Windows 防火墙须允许应用的入站连接：共享端口的 TCP 和 47653 端口的 UDP。首次启动共享时 Windows 通常会询问一次，应用不会自动修改防火墙规则。

## 共享与网络

- 共享默认关闭。关闭设置面板后共享继续，关闭共享开关或退出主机应用才会结束。
- 支持局域网地址及 Tailscale 私有地址范围；Tailscale 跨节点连接尚未验证。不支持公网直连或 HTTPS。
- HTTP 不提供传输加密，只应在受信任网络中共享。Tailscale 连接依赖其自身的网络保护。
- 主机同时运行本地转录与共享时，会额外占用内存或显存。繁忙时客户端会收到提示。

## 数据与中断

文稿保存在客户端，主机不保存客户端文稿或原始录音。导入的文件由客户端读取，分段发送音频，不复制整个原文件到主机。主机只共享本地模型，不代理云端服务。

暂停停止新采集；遗弃取消当前任务并删除客户端文稿，不关闭主机。关闭主机共享会中断客户端任务；断线时保留已完成文字，翻译失败时保留原文。

目前没有自动重连、音频续传、任务迁移或记录同步。客户端保存一个主机，凭据加密保存；主机只在设置目录旁的 `devices.json` 中保存每台设备凭据的哈希值，这个文件无法用来连接。
